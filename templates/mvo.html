Análisis de datos del nivel del mar en Colombia · SIMMAR-IoT

📋

Descripción del Proyecto

¿De qué trata?

SIMMAR-IoT es un proyecto de análisis de datos enfocado en el comportamiento histórico del nivel del mar en dos estaciones costeras de Colombia: TESORO INVEMAR (costa Caribe, Bolívar) y JUANCHACO - AUT (costa Pacífica, Valle del Cauca). A partir de datos reales recopilados entre 2019 y 2020, se construyó un Data Warehouse, se realizaron análisis exploratorios y se desarrolló una plataforma web interactiva para la visualización de los resultados.

🔭

Alcance

¿Qué abarca el proyecto?

El proyecto abarca el análisis de más de 64 mil mediciones del nivel del mar registradas por sensores IoT en las costas colombianas. Se construyó un modelo dimensional (Data Warehouse) con tablas de hechos y dimensiones, se integraron los datos en Power BI para su visualización interactiva, y se desarrolló una plataforma web conectada en tiempo real a la base de datos en la nube, permitiendo explorar tendencias, comparativos por ubicación y análisis temporales.

🏆

Objetivos del Proyecto

¿Qué se logró?
  • 🗄️ Diseñar e implementar un Data Warehouse con datos históricos del nivel del mar en Colombia.
  • 📊 Analizar el comportamiento temporal y geográfico del nivel del mar entre 2019 y 2020.
  • 📈 Desarrollar visualizaciones interactivas en Power BI que permitan identificar tendencias y patrones.
  • 🌐 Construir una plataforma web conectada a la base de datos en la nube para consulta pública de los resultados.
  • 🗺️ Georreferenciar las estaciones de monitoreo y comparar el comportamiento entre la costa Caribe y la costa Pacífica.
🛠️

Tecnologías Utilizadas

Stack tecnológico del proyecto
🗄️

SQL Server · somee.com

Base de datos en la nube con modelo dimensional (Data Warehouse). Tablas: Fact_NivelMar, Dim_Estacion, Dim_Tiempo, Dim_Ubicacion.

📊

Power BI

Reporte interactivo con 5 páginas de análisis: Resumen Ejecutivo, Análisis por Tiempo, Ubicación, Dispositivos y Detalle de Mediciones.

🐍

Python · Flask

Backend de la plataforma web desarrollado en Flask, con APIs REST que conectan la interfaz con la base de datos en somee.

🌐

Render · GitHub

Plataforma web desplegada en Render con integración continua desde GitHub. Disponible públicamente en simmar-iot.onrender.com.
